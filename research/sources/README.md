# Fuentes externas y material excluido

Las notas de investigación citan materiales de terceros (obras de Laban y Kaparo, un PDF de tesis, CMU mocap y respuestas de estudios publicados). Sus originales no se redistribuyen en este repositorio. Consultar los enlaces y condiciones de uso que constan en [`../BIBLIOGRAPHY.md`](../BIBLIOGRAPHY.md) y en cada nota.

Aquí sólo se conservan contratos públicos usados para auditoría y videos **sintéticos propios** del banco de fase. Algunos scripts de reanálisis requieren volver a descargar la fuente original; los resultados previos se mantienen identificados como reanálisis externos, nunca como observaciones de Nico.
